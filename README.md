# LeetCode X

My LeetCode solutions, organized by programming language. Each language has its own branch and project structure.

| Language | Branch |
| --- | --- |
| Elixir | [elixir](https://github.com/veryshyjelly/leetcode-x/tree/elixir) |
| Rust — Striver sheet | [rust-striver](https://github.com/veryshyjelly/leetcode-x/tree/rust-striver) |

The Elixir branch contains the solution files, Mix configuration, and tests imported from [Leetcode-Elixir](https://github.com/veryshyjelly/Leetcode-Elixir).

The `rust-striver` branch contains the complete project imported from [striver-sheet-solutions-rust](https://github.com/veryshyjelly/striver-sheet-solutions-rust), including its original auxiliary Go solutions.

Branch names identify the language and, where needed, the collection: `rust-striver` is for the Striver sheet, while `rust` can be used for independent Rust practice.
